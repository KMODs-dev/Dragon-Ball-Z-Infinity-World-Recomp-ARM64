# Dragon-Ball-Z-Infinity-World-Recomp-ARM64
A port of Dragon Ball Z Infinity World for Android phones with ARM64.
already playable on a low-end device with a Helio G85 and 4GB of RAM.
For now it's not available for 32-bit phones, but support may be added in the future.
